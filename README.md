# Become a Teacher 🎓

A life-journey career simulation game.

## Gameplay
- Start with 1,000 virtual coins.
- Progress from school to education leadership.
- Complete missions to earn coins, education, teaching skill and XP.
- Unlock and select multiple characters.
- Buy virtual rooms, desks, homes, cars, villas and an academy.
- Progress is saved in the browser with localStorage.

## Run
Open `index.html` in a modern browser or enable GitHub Pages for the repository. Coins and purchases are virtual game data only.
